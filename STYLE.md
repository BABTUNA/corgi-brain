# Corgi Brain style

The short version for anyone, or any agent, touching the UI. Tokens live in `bridge/public/bb.css`; logo files in `assets/logo/`.

| Use | File |
|---|---|
| Wordmark on light backgrounds | `assets/logo/supabrain-wordmark.svg` |
| Wordmark on dark backgrounds | `assets/logo/supabrain-wordmark-dark.svg` |
| Mark only | `assets/logo/supabrain-mark.svg` (`-dark`, `-mono`, `-on-green` variants) |
| App icon / favicon | `assets/logo/supabrain-icon.svg`, `assets/icons/icon-{16..512}.png` |

**Colour.** Greens on neutral greys. Bright green `#3ECF8E` for dots, bars, highlights and the extension's glow. Buttons and green text use the darker `--orange-ink` (`#127A54`) so white text stays readable. Ink `#171717`, paper `#F8F8F7`, lines `#E4E4E2`. No orange.

**Type.** Archivo 800 for headings, Onest for body text, JetBrains Mono for labels, chips and numbers.

**Voice.** Short, plain sentences. Say who taught a workflow. Never claim an agent succeeded when the judge disagreed.
