# Assets

| Folder | What's in it |
|---|---|
| `logo/` | Supa Brain wordmark, mark and icon as SVG (light, dark, mono and on-green variants) |
| `icons/` | App and extension icons, 16 to 512 px |
| `banner/` | README banner and wordmark PNGs |
| `render/` | Source HTML and fonts used to render the PNGs |
| `brand.css` | Colour and type tokens |

The web app uses its own copy of the logo and icons in `bridge/assets/` so it can be deployed on its own.
