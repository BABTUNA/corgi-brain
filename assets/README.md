# Assets

| Folder | What's in it |
|---|---|
| `logo/` | Corgi Brain mark, wordmark and icon as SVG (light, dark, mono and on-fawn variants) |
| `icons/` | App and extension icons, 16 to 512 px |
| `banner/` | README banners, wordmark PNGs and the logo sheet |
| `png/` | Transparent logo PNGs, 16:9 covers and square tiles for slides and forms |
| `render/` | Generator scripts and the Archivo font used to outline the words |
| `brand.css` | Colour and type tokens |

See `../STYLE.md` for how to use them. The web app uses its own copy of the logo and icons in `bridge/assets/` so it can be deployed on its own.
