Agents that didn't have to explore

Every time an agent asks Corgi Brain instead of clicking around a site, the saved path runs in a headless browser in seconds, with no model calls. When a site has changed, the path heals itself and the library is updated for the next agent.

Connect your agent

Corgi Brain is an MCP server. Add it to Claude Code (it is already in this repo's .mcp.json) or any MCP client, and your agent looks up a verified path before it starts clicking.

{
  "mcpServers": {
    "corgi-brain": { "command": "node", "args": ["mcp/server.js"] }
  }
}
